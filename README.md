# 📱 PocketPrice India

**Find the right smartphone at the right price.**

PocketPrice is a smartphone discovery and price-comparison website focused on budget-friendly and refurbished phones in India. It helps users explore available listings, compare key specifications, and discover deals that fit their budget.

🔗 **Live Website:** [pocketprice.vercel.app](https://pocketprice.vercel.app)

---

## ✨ Features

- 🔎 **Smartphone Search** — Find phones by name and explore available listings.
- ⚖️ **Phone Comparison** — Compare important specifications to make informed decisions.
- 💰 **Budget-Friendly Discovery** — Explore affordable and refurbished smartphone options.
- 🔃 **Sorting and Filtering** — Narrow down options based on available criteria.
- ❤️ **Saved Phones** — Keep track of phones you're interested in.
- 📖 **Buying Guides** — Get practical tips for choosing budget and refurbished smartphones.
- 📱 **Responsive Interface** — Browse across desktop and mobile devices.
- 🔗 **Retailer Links** — Visit retailer listings to verify current prices, availability, and product details.

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) installed
- npm (included with Node.js)
- Git

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/arkaprabha2005/pocketprice.git
   ```

2. Navigate to the project directory:

   ```bash
   cd pocketprice
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.

### Production Build

To create a production build, run:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```

## 📊 Price and Listing Accuracy

Smartphone prices and availability can change frequently. Listings displayed on PocketPrice should be treated as informational snapshots rather than guaranteed live inventory.

Before purchasing, users should verify:

- The exact model and storage variant
- Device condition and warranty
- Current price and stock status
- Seller reliability and return policy

PocketPrice aims to make smartphone discovery easier while encouraging informed purchasing decisions.
